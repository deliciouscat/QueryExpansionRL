# Experiment entrypoints

`CODE_INTERFACE.md`가 정한 형태로 실험별 `<훈련id>.py`를 둔다. 이 디렉터리는 모듈들을 초기화하고 연결하는 통합 담당자가 관리한다.

Entry point에는 데이터 스트림, 모델, 보상 등 구성 요소의 선택과 초기화, forward/loss를 포함한 학습 흐름, 저장 정책을 읽을 수 있게 작성한다. 구성 요소의 내부 구현은 각 담당 모듈에서 제공하며 이 디렉터리에서 복제하지 않는다.

모듈 API 변경이 필요하면 담당자와 조율하고, 각 전문가는 본인 소유 모듈 디렉터리만 수정한다.
