General Prompt:
In order to retrieve supporting documents to answer the given question, you need to rewrite and extend a given question into one new query. Remember that the rewritten query is not limited to a simple question, but can be a passage including multiple sentences that provides context for the input question. Here are some commonly used query rewriting methods, please select one appropriate method and use it to generate one new rewritten query:
1. Query Understanding: Extract core information from the query, and understand the core elements. For example, ‘What was the federal alternative minimum tax credit carryforwards?’ can be phased as ‘Federal, U.S. federal tax system; Alternative Minimum
Tax (AMT), a parallel tax system designed to ensure taxpayers pay a minimum level of tax; Credit carryforwards, unused credits that can be carried forward to future years to offset regular tax liability;’. 2. Semantic Rewriting: (1) Identify important entities and expand with related information. For example, ‘Steve Jobs’ to ‘Apple
CEO Steve Jobs’. (2) Add broader (hypernym) or more specific (hyponym) concepts. For example, ‘husky’ to ‘pet dog husky’. (3) Change word order or phrasing to match common expressions in target documents. For example, ‘make steak’ to ‘steak recipe tutorial’. 3. Query Decomposition: Break down a complex query into multiple sub-queries for separate retrieval. For example, ‘Which stock price is higher, Apple or Google?’ to ‘<rewrite>what is the stock price of Apple?</rewrite><rewrite>what is the stock price of Google?</rewrite>’. Also consider more complex queries that can benefit from breaking down into multi-hop queries. 4. General Rewriting: (1) Paraphrasing: rephrase the whole query if you think can possibly help the embedding model generate more accurate embeddings. For example, ‘How to lose weight effectively?’ to ‘What are some scientifically proven weight loss methods?’. (2) Intent Refinement, infer the user true intent and rewrite the query accordingly. (3) Multi-hop Query Generation, generate indirectly related queries that help improve recall. For example, ‘diabetic diet’ to ‘fruits suitable for diabetics’. 5. Hypothetical Document Generation: Generate a hypothetical target document, in order to use this hypothetical document to retrieve target document. For example, (1) Given a question asking about the law clause related to a case, directly generate a hypothetical clause for retrieval. (2) Given a question about a company’s stock, directly generate a hypothetical stock price report that looks alike the target document that contains the information.
